# Как запустить приложение Spark командой spark-submit

> **Учебная работа.** Справка подготовлена на основе публичной документации Apache Spark (раздел Submitting Applications). В официальную документацию проекта она не входит.

**Для кого:** для начинающего разработчика или аналитика данных, который установил Spark и хочет запустить первое приложение.

**Что понадобится:** установленный Spark, Java подходящей версии (требования указаны в документации вашей версии Spark) и терминал.

Spark — это движок для обработки данных, и любую программу под него нужно как-то запустить. Для этого есть `spark-submit`: одна команда, которой можно отправить приложение и на ваш ноутбук, и на кластер из многих машин. Звучит солидно, но для первого запуска хватит одной строчки. Давайте разберём её по частям.

## Что делает spark-submit

Скрипт из каталога `bin/` отправляет приложение на выполнение: на вашем компьютере, на кластере или в Kubernetes. Ниже запускается учебный пример `pi.py` из поставки Spark, кластер для него не нужен.

## Шаг 1. Подготовьте команду

Ниже общий вид команды. Не пугайтесь количества параметров: в учебном примере понадобится только `--master`, остальные пригодятся позже, когда приложение переедет на кластер.

Общий вид команды:

```bash
./bin/spark-submit \
  --class <главный-класс> \
  --master <адрес-мастера> \
  --deploy-mode <режим> \
  --conf <ключ>=<значение> \
  <jar-или-py-файл> \
  [аргументы приложения]
```

| Параметр | Назначение |
|----------|------------|
| `--class` | Точка входа. Нужен для приложений на Java и Scala, для Python не указывается |
| `--master` | Где выполнять приложение (значения в таблице ниже) |
| `--deploy-mode` | Где запускать драйвер: `client` (по умолчанию) или `cluster` |
| `--conf` | Параметр конфигурации в виде `ключ=значение` |

| Значение `--master` | Что означает |
|---------------------|--------------|
| `local` | Один рабочий поток, параллелизма нет |
| `local[K]` | K рабочих потоков |
| `local[*]` | Столько рабочих потоков, сколько логических ядер на машине |
| `spark://ХОСТ:ПОРТ` | Автономный кластер Spark |
| `yarn` | Кластер Hadoop YARN |
| `k8s://ХОСТ:ПОРТ` | Кластер Kubernetes |

## Шаг 2. Запустите учебное приложение

1. Откройте терминал и перейдите в каталог установки Spark.
2. Выполните команду:

   ```bash
   ./bin/spark-submit --master "local[4]" examples/src/main/python/pi.py 10
   ```

   Значение `local[4]` означает, что приложение выполняется на вашем компьютере в четырёх потоках. Кластер для этого не нужен.

3. Дождитесь завершения работы. Это не должно занять много времени: основное время уходит на запуск самого Spark.

Пример `pi.py` уже лежит в поставке Spark, поэтому ничего скачивать не нужно. Он приближённо вычисляет число π: бросает множество случайных точек в квадрат и смотрит, какая их часть попала в вписанный круг. Число `10` в конце команды говорит, на сколько частей разделить расчёт.

## Шаг 3. Проверьте результат

Среди служебных сообщений найдите строку вида `Pi is roughly 3.14...`. Число после слов «roughly» приближённое и при каждом запуске немного отличается: приложение вычисляет его на случайных числах.

Если строки нет, перейдите к разделу «Типичные проблемы».

Если служебных сообщений слишком много, а нужна только эта строка, перенаправьте вывод в `grep`:

```bash
./bin/spark-submit --master "local[4]" examples/src/main/python/pi.py 10 2>&1 | grep "Pi is roughly"
```

## Режимы развёртывания

Слово «драйвер» звучит загадочно, а суть простая: это главный процесс вашего приложения, который раздаёт задачи остальным. В режиме `client` он работает на вашей машине, в режиме `cluster` — где-то внутри кластера.

| | `client` | `cluster` |
|---|----------|-----------|
| Где работает драйвер | На машине, где выполнена команда | На одном из узлов кластера |
| Подходит для | Отладки и интерактивной работы | Рабочих запусков на кластере |

> **Важно.** В режиме `cluster` файлы, которые читает приложение, должны быть доступны с узлов кластера, а не только с вашего компьютера.

> **Ограничение.** Возможность использовать режим `cluster` зависит от менеджера кластера. Например, автономный кластер Spark (standalone) не поддерживает режим `cluster` для приложений на Python.

## Типичные проблемы

Первый запуск редко проходит гладко, и это нормально. Вот три ситуации, с которых имеет смысл начать поиск.

| Что вы видите | Причина | Что делать |
|---------------|---------|------------|
| `JAVA_HOME is not set` | Spark не нашёл Java | Установите Java и задайте переменную `JAVA_HOME` |
| `Could not parse Master URL` | В `--master` указано недопустимое значение | Сверьте значение с таблицей выше |
| Сообщение о том, что файл приложения не найден | Неверный путь к `.py` или `.jar` | Проверьте путь относительно текущего каталога |
