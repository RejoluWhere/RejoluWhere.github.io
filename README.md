# Портфолио технического писателя

Сайт: https://rejoluwhere.github.io

Все работы носят учебный характер для показа основных навыков в ходе работы "Junior Технический писатель". Они написаны по материалам открытого проекта Apache Spark и в его официальную документацию не входят. Команды и примеры составлены по документации Spark; на кластерах я их не запускал. Да и в целом, портфолио носит характер окончания небольшой прогулки в роли технического писателя.

## Состав

| Файл | Что это |
|------|---------|
| `index.html` | Страница портфолио (один файл, без сборки) |
| `works/spark-submit-guide.md` | Инструкция по запуску приложения через `spark-submit` |
| `works/spark-sql-groupby.md` | Готовые запросы Spark SQL с группировкой |
| `works/spark-docs-contribution.md` | Как исправить документацию Spark и собрать её локально |
| `works/spark-submit-operator-guide.docx` | Руководство оператора в Word, структура по ГОСТ 19.505-79 |
