Описать запуск приложения через spark-submit (русскоязычная справка)

Проект
Spark
Компонент
Documentation
Связано с
Pull Request «[SPARK-XXXXX][DOCS] ...» в apache/spark
Исполнитель
Технический писатель

Цель. Подготовить справку по запуску приложений через spark-submit на основе страницы Submitting Applications в документации Spark.

Критерии готовности

  • описаны синтаксис команды и основные параметры;
  • приведена таблица значений --master;
  • пример запуска выполнен локально, результат совпадает с описанием;
  • даны ссылки на оригинальную страницу документации;
  • текст прошёл ревью.
project = SPARK AND component = Documentation AND status = Open
ORDER BY updated DESC
